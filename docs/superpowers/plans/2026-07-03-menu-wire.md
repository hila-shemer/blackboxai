# Menu-Wire Implementation Plan (productize-v1, wave 1, lands 5th)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The parsed menu file becomes the live root menu - `[include]`/`[style]`/`[stylesdir]`/`[reconfig]`/`[restart]{cmd}` get real semantics, the menu stat-reloads on open like classic, and restart leaves by exec-after-teardown.

**Architecture:** Everything stays in the existing three-layer shape: pure parser (`MenuParser`) grows the missing directives behind injectable file-loader/dir-lister seams; a pure fixup (`rootmenu::buildFromParsed`) turns a parsed tree into the live tree (workspace fill, disabled config mount, in-code fallback); `Server::openRootMenu` swaps its source and gains classic checkMenu stat-on-open reload. Restart is pending-argv + `wl_display_terminate`; `main.cc` execs after full teardown.

**Tech Stack:** C++20, meson+ninja, doctest, headless golden-PNG harness (`tests/harness/`). No new wlroots surface - the only new syscalls are POSIX stat/readdir/execvp.

## Locked decisions binding this plan (and critique responses)

- **Exec-restart ships, documented.** On Wayland the compositor is the display server - restart (self or another WM) kills every client. Implemented classic-shaped (teardown, then exec; `reference/blackboxwm/src/blackbox.cc:583-605`), the caveat lives as a comment in `main.cc` and MUST be carried into the wave-3 man page (noted for the program orchestrator).
- **Pipe menus (`|cmd`) skip-with-diagnostic** - explicit v1 non-goal (locked). Both the `[include]` form and a pipe `menuFile`. popen at menu-open would block the compositor loop; acceptance 6.1 reads "menu files load unchanged, pipe-menu entries excepted (diagnosed, not silent)".
- **Fallback menu = the richer in-code menu** (kitty/xterm/Workspaces/Restart/Exit, `src/Rootmenu.cc:43-57`), not classic's xterm/Restart/Exit stub - decided on product grounds (a daily driver wants a terminal and workspaces on a broken first boot). The zero-golden-churn effect is a side benefit, not the reason.
- **Shell policy asymmetry, stated out loud:** menu `[exec]` and `[restart]{cmd}` are user-authored, they go through `/bin/sh` (parser emits the argv). Style-file rootCommand never execs - that is rc-style's side and this slice does not touch it.
- **`[reconfig]{cmd}`: code over doc.** The man page documents a shell command; reference code never reads it (`reference/blackboxwm/src/Screen.cc:1755-1764`). We drop it with a diagnostic naming the dropped command.
- **Territory sprawl acknowledged** (critique): this slice touches Server.{hh,cc}, main.cc, MenuItem.hh, toolkit/Util - beyond the spec table's "Owns: Rootmenu". The synthesis contention map supersedes the spec table; the discipline here is additive-only in shared files and the hottest lines (`activateMenuItem` switch) change in exactly two tasks (1 and 8).
- **`[config]` placeholder is user-visible at the checkpoint** - rendered disabled (not selectable, no hover-open) so it cannot confuse the TTY hand-check.
- **Reload = classic checkMenu parity** (stat-on-open, `reference/blackboxwm/src/blackbox.cc:635-650`), no inotify, no timers. We store the full `st_ctim` timespec (nanoseconds) instead of classic's whole seconds - same shape, deterministic tests.

```cpp
#include "Util.hh"

#include <cstdlib>

namespace bt {

  std::string expandTilde(const std::string &path) {
    if (path.empty() || path[0] != '~') return path;
    if (path.size() > 1 && path[1] != '/') return path;  // "~user" unsupported, like reference
    const char *home = std::getenv("HOME");
    if (!home) return path;
    return std::string(home) + path.substr(1);
  }

} // namespace bt
```

```cpp
  FileLoader defaultFileLoader() {
    return [](const std::string &path, std::string &text) {
      struct stat st;
      if (stat(path.c_str(), &st) != 0 || !S_ISREG(st.st_mode))
        return false;                        // classic [include] S_ISREG check
      std::ifstream f(path, std::ios::binary);
      if (!f) return false;
      std::ostringstream ss;
      ss << f.rdbuf();
      text = ss.str();
      return true;
    };
  }

  DirLister defaultDirLister() {
    return [](const std::string &dir, std::vector<std::string> &names) {
      DIR *d = opendir(dir.c_str());
      if (!d) return false;
      while (dirent *p = readdir(d)) {
        const std::string name = p->d_name;
        if (name == "." || name == "..") continue;
        struct stat st;
        if (stat((dir + "/" + name).c_str(), &st) == 0 && S_ISREG(st.st_mode))
          names.push_back(name);
      }
      closedir(d);
      return true;
    };
  }

  Result parse(const std::string &text,
               const FileLoader &loader, const DirLister &lister) {
    Result r;
    Ctx ctx{loader, lister, r, 0};
    const std::vector<std::string> lines = splitLines(text);
    std::size_t idx = 0;
    parseLevel(lines, idx, r.items, ctx, &r.title);
    return r;
  }

  Result parseFile(const std::string &path,
                   const FileLoader &loader, const DirLister &lister) {
    std::string text;
    if (!loader(path, text)) {
      Result r;
      r.diagnostics.push_back("cannot open menu file: " + path);
      return r;
    }
    Result r = parse(text, loader, lister);
    r.files.insert(r.files.begin(), path);   // main file first, includes after
    return r;
  }
```

```cpp
#include "Server.hh"

#include <cstring>
#include <cstdio>
#include <string>
#include <unistd.h>   // execvp
#include <vector>

int main(int argc, char **argv) {
  bool headless = false;
  for (int i = 1; i < argc; ++i)
    if (std::strcmp(argv[i], "--headless") == 0) headless = true;

  bool restart = false;
  std::vector<std::string> restart_argv;
  {
    bbai::Server server(headless);
    if (!server.ok()) {
      std::fprintf(stderr, "blackboxai: failed to initialise the compositor\n");
      return 1;
    }
    server.run();
    restart = server.restartRequested();
    restart_argv = server.restartArgv();
  }   // full teardown first - the exec below must not inherit a live display

  if (restart) {
    // Restart on Wayland, documented plainly: the compositor IS the display
    // server, so a restart (self or another WM) takes every client down with
    // it. Classic shape otherwise (blackbox.cc restart()): shell-exec the
    // named WM, fall back to re-execing ourselves.
    if (!restart_argv.empty()) {
      std::vector<char *> cargv;
      for (std::string &s : restart_argv) cargv.push_back(s.data());
      cargv.push_back(nullptr);
      execvp(cargv[0], cargv.data());
      std::perror("blackboxai: restart");    // exec failed - fall through to self
    }
    execvp(argv[0], argv);                   // re-exec ourselves (bare [restart])
    std::perror("blackboxai: restart self");
    return 1;
  }
  return 0;
}
```
